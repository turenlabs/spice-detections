# IronWorm npm compromise - June 2026

Source:

- JFrog Security Research: The IronWorm: A New Wave of npm Supply Chain Attacks
  (https://research.jfrog.com/post/iron-worm-shai-hulud-rustier-cousin/)

Pack: `ironworm-2026-06`

## Summary

JFrog reported IronWorm as a June 2026 npm compromise affecting 37 packages across WeaveDB,
Warp Contracts, Arweave, and RedStone package families. The attacker added a `preinstall` hook that
ran `./tools/setup`, then used repository write access and GitHub Actions workflow changes for
propagation and secret collection.
