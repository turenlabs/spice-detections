# IronWorm npm compromise - June 2026

Sources:

- JFrog Security Research: The IronWorm: A New Wave of npm Supply Chain Attacks
  (https://research.jfrog.com/post/iron-worm-shai-hulud-rustier-cousin/)
- OSV: [hbsig MAL-2026-5190](https://osv.dev/vulnerability/MAL-2026-5190),
  [wao MAL-2026-4711](https://osv.dev/vulnerability/MAL-2026-4711), and
  [weavedb-base MAL-2026-4715](https://osv.dev/vulnerability/MAL-2026-4715)

Pack: `ironworm-2026-06`

## Summary

JFrog reported IronWorm as a June 2026 npm compromise affecting 37 exact package/version pairs
across WeaveDB, WDB, CWAO, ArNext, and related package families. The attacker added a `preinstall`
hook that ran `./tools/setup`. JFrog observed the binary/dropper path in compromised packages and
also found a functional GitHub Actions propagation and secret-collection path, but did not observe
that workflow path trigger during its investigation.

## July 14 data correction

The pack CSV was replaced wholesale on July 14. Its prior 37 rows did not match JFrog's published
IOC table and must not be treated as an earlier authoritative snapshot. The corrected CSV contains
all 37 JFrog rows plus four exact versions confirmed by the cited OSV records:
`hbsig@0.3.1`, `wao@0.41.3`, `wao@0.41.4`, and `weavedb-base@0.45.4`.
Together with JFrog's `hbsig@0.3.2`, `wao@0.41.2`, and `weavedb-base@0.45.3`, those records make
the version deltas explicit and auditable.

## Added coverage

- 41 exact npm package/version rows: JFrog's 37 authoritative table rows and four OSV-confirmed
  deltas.
- Standalone IOC for the `./tools/setup` preinstall hook.
- Standalone IOC for the npm trusted-publishing OIDC token-exchange path.
- Composite IOC for package manifests or tarball contents that combine the actual affected package
  families, `tools/setup`, the preinstall hook, and the spoofed Claude noreply author.
- Composite IOC for the workflow secret-artifact pattern using `VARIABLE_STORE`,
  `toJSON(secrets)`, `format-results.txt`, and pinned GitHub Actions SHAs.

## Scan notes

Generic extensionless names `setup` and `precheck` were removed from `suspiciousFilenames` because
archive filename presence alone can create a high-severity finding. The exact versions and content
IOCs retain coverage without treating common filenames as malicious.
